# AI Contest Hub

짙은 초록색과 민트색을 유지한 반응형 AI 공모전 웹 서비스입니다. 기존 HTML/CSS/JavaScript와 Supabase API 구성을 사용하며 별도 프레임워크나 빌드 의존성을 추가하지 않습니다.

## 웹에서 할 수 있는 일

- PC의 상단 메뉴·분야별 사이드 메뉴와 모바일 하단 메뉴로 홈, 탐색, 저장, 마이 허브 이동
- 제목·주최기관·키워드 검색과 분야, AI 사용 조건, 지역, 모집 상태 필터 조합
- 추천순·마감일순·상금순·최신순 정렬, 카드·목록 보기와 24개 단위 더 보기
- 관심 기회 저장, 공식 요강 확인, 키보드로 상세창 탐색 및 닫기
- 기존 회원가입·로그인·비밀번호 재설정·출석·수상 인증·관리 기능

`app.js`는 `/supa` API 프록시를 사용합니다. `vercel.json`의 기존 Supabase rewrite를 유지해야 합니다. 로컬에서 백엔드까지 실행하려면 Vercel 프로젝트에 연결한 뒤 `vercel dev`를 사용하세요. 단순 정적 파일 서버만으로는 이 프록시가 제공되지 않습니다.

## 표시 기준

- 날짜만 있는 마감일은 한국 시간의 해당 날짜 마지막까지 유효한 것으로 표시합니다. 시간이 있는 마감일은 지정된 시각을 따릅니다.
- 날짜가 없는 기회는 `일정 확인`으로 표시합니다. 상시 모집이라고 단정하지 않습니다.
- 접수 상태 필터는 `status=live`로 공개된 데이터 안에서 마감일을 기준으로 분류합니다. `마감 포함 전체`는 비공개·보관 데이터까지 불러오는 기능이 아닙니다.
- 상금순은 기존 고정 환산율로 계산한 참고 순서입니다. 실제 금액과 참가 가능 여부는 공식 모집요강을 확인해야 합니다.
- 비회원 저장은 현재 브라우저에 보관됩니다. 로그인 시 기존 계정의 저장 목록을 불러오고 이후 변경을 동기화합니다.

## 파일

- `index.html`: 페이지 구조와 기존 계정·리워드 화면
- `web.css`: 반응형 레이아웃, 카드·목록, 상세창, 접근성 스타일
- `app.js`: 검색·필터·저장·날짜 표시와 기존 계정 연동
- `style.css`, `admin.css`, `admin.js`, `recovery.js`: 기존 기본 스타일 및 관리·계정 기능
- `detail-save.js`: 이전 모바일 버전의 보완 스크립트. 웹 버전에서는 관련 기능을 `app.js`에 통합하여 중복 로드하지 않습니다.
